# 💬 Real-Time Chat Application

> 🏗️ **Learning Sandbox:** This repository serves as my primary stepping stone for mastering full-stack web development. Instead of building isolated tutorials, I am consolidating everything I learn into this single, living chat application.

### 🛠️ The Tech Stack
* **HTML5:** Crafting semantic layouts and structuring the chat interface.
* **CSS3:** Designing responsive layouts, chat bubbles, and custom UI components.
* **JavaScript:** Handling application logic, DOM manipulation, and asynchronous events.
* **Supabase:** Managing the backend database, user data, and real-time message streams.

### 📈 Project Status
**ACTIVE DEVELOPMENT.** This codebase is a work-in-progress and reflects my ongoing learning journey. It will constantly evolve, change, and improve as I experiment with new features, fix bugs, and expand my technical skills.
